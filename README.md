# lark-bilingual

同时打开一篇 Lark / 飞书文档和它的翻译版（两篇独立的文档），让两边联动：

- **选中联动**：在一边选中文字或点一下某段，另一边对应的段落高亮并滚到视野内。
- **滚动同步**：滚动一边，另一边跟到同一段的同一位置。按段落对齐，不按像素，两种语言段落高度不同也不会越滚越偏。
- **表格横向滚动同步**：横向滚一边的表格，另一边同一张表跟着走。

适合跨语言会议：一边讲中文版，另一边的同事看着英文版，位置始终对得上。

## 前提

- macOS、Google Chrome、Node.js 22 或更高版本
- 已登录的 [lark-cli](https://github.com/larksuite/cli)（用来读取两篇文档的段落结构）
- Chrome 菜单里打开「视图 → 开发者 → 允许 Apple 事件中的 JavaScript」

  这个开关打开期间，本机上获得了控制 Chrome 权限的程序都能在你的网页里执行代码。介意的话用完关掉，或者用下面的 `--isolated` 方式。

## 用法

**接管已经打开的两篇**：在 Chrome 里打开两篇文档（两个窗口各一篇，或同一窗口里用 Chrome 分屏的两个标签页），然后运行：

```bash
node lark-bilingual.mjs
```

开着不止两篇 Lark 文档时，把要对照的两篇链接作为参数传入：

```bash
node lark-bilingual.mjs <文档A链接> <文档B链接>
```

这两篇如果还没打开，工具会开左右两个窗口。按 Esc 清除高亮；关掉这两篇文档或按 Ctrl+C 退出，退出时会把页面里的联动脚本卸掉。

| 选项 | 作用 |
|---|---|
| `--no-scroll` | 只联动高亮，不同步滚动 |
| `--isolated` | 不用上面那个开关，改为启动一个独立配置的 Chrome，通过调试接口注入。需要在里面另登录一次 Lark |
| `--gui` | 提示和报错用系统对话框，供下面的应用使用 |

**做成可双击的应用**：

```bash
./build-app.sh
```

会生成 `~/Applications/Lark 双语对照.app`。双击后它自己找 Chrome 里开着的 Lark 文档：正好两篇就直接接管，多于两篇让你选，没有就让你粘贴链接。

## 原理

1. 用 lark-cli 读取两篇文档的块列表（段落、标题、列表项、表格等，每块有唯一 ID）。
2. 两篇的块类型顺序一致时按顺序一一配对；不一致时按块类型序列求最长公共子序列，尽量对齐。
3. 把联动脚本注入两个页面。Lark 页面上每个块的 `data-record-id` 就是接口返回的块 ID，据此找到对应的块。
4. 两个页面同域，用 `BroadcastChannel` 互相传消息，不经过任何服务器，也不开本地端口。

几个细节：

- 高亮只写一条样式规则，不改文档里的任何节点。
- Lark 只渲染视口附近的块，目标块不在页面里时，脚本会边滚边找。
- 只有正在被操作的那一边才发出滚动位置，避免两边互相推着走。
- Lark 表格的横向滚动不是原生滚动条，脚本读写的是表格内部容器的滚动位置。

## 限制

- 译文需要和原文结构基本一致（比如复制原文后逐段翻译）。增删过段落的位置附近可能对不准。
- 对应关系在启动时生成，文档增删段落后要重新运行。
- 表格横向同步用的是同一个像素位置。两栏宽度不同时，较宽的一栏会先滚到头。
- 依赖 Lark 网页的内部结构，Lark 改版后可能需要调整。
- 只支持 macOS 上的 Chrome。
